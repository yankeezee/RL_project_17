## Зафиксированные технические соглашения

1. Independent sampling with replacement для всех четырёх методов. Это обеспечивает
   совместимость фактических вероятностей с указанной формулой importance weights.
   Готового PER для сравнения его соглашений не было.
2. Повторы в batch считаются отдельными draws и участвуют в loss отдельно.
   Priority refresh одного перехода использует `max(abs(delta))` по повторам,
   независимо от порядка. В детерминированной сети одинаковые переходы обычно
   дают одинаковые остатки. Изменение этого правила при интеграции фиксировать для всех методов.
3. Raw priority = `abs(delta)+1e-6`; масса `u=raw**0.6`. Первый raw priority = 1.0.
   Вставка берёт максимум текущего буфера непосредственно **до** удаления FIFO-жертвы.
   Это явное уточнение неоднозначного порядка операций в полном буфере.
4. Остаток вычисляется для loss перед optimizer.step; приоритет обновляется после step
   этим detached остатком. Дополнительный post-step forward pass не делается.
5. Beta следует общему decision clock, включая warm-up: .4 + .6*min(decisions/300000,1).
6. Huber threshold = 1; reduction = `mean(weight * loss)`. Нормировка weights глобальная.
7. Один процесс/поток sampler. Payload хранится по ссылке; caller передаёт стабильные
   снимки observation/history. Async/distributed replay и возобновление обучения не реализованы.
8. Frozen export содержит metadata приоритетов, тегов и replay counts, но не observations.
   Это аналитический снимок, не checkpoint для resume.

## Расхождения со спецификацией

Обнаруженных содержательных противоречий между пользовательским запросом,
приложенным proposal и реализованными формулами нет. Соглашения выше уточняют
неопределённые детали; готовый код команды для проверки совместимости отсутствует.
Synthetic demo и benchmark используют уменьшенные/искусственные данные для проверки,
они явно помечены и не считаются экспериментальными training runs.

Не подтверждены исполнением: корректность реальной среды/истории, labels API,
dropout process, общий training schedule, paired masks/seeds, hit rate и bootstrap.
Их отсутствие не заменено экспериментальными утверждениями.
